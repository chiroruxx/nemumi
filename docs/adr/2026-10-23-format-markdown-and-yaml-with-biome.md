# Markdown と YAML の整形を Biome に統一する

- **ステータス**: 承認
- **決定日**: 2026-10-23

## 背景

Biome の更新により Markdown と YAML も整形対象となった。Markdown を JetBrains IDE で整形する従来の方針では、ローカルの整形結果と CI の検査が競合する。

## 決定

Markdown と YAML の整形にも Biome を使用し、リポジトリ共通の整形・検査に統一する。
[Formatter / Linter に Biome を採用する](2026-09-24-formatter-linter-biome.md)の Markdown を対象外とする決定を置き換える。

## 検討した選択肢

| 選択肢                                     | 評価                                               |
| ------------------------------------------ | -------------------------------------------------- |
| **Biome に統一する**                       | ローカルと CI で同じ整形結果を検査できる           |
| Markdown を対象外にして IDE の整形を続ける | 整形ツールの使い分けと除外設定を維持する必要がある |

## 結果

- **良い点**
  - IDE の有無によらず、共通のコマンドで整形できる。
- **注意点**
  - 既存文書や YAML にも整形差分が発生するため、構造と内容が維持されていることを確認する。
