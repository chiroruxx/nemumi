# 安定版の Biome ルールで存在確認と変数参照の意図を検査する

- **ステータス**: 承認
- **決定日**: 2026-10-23

## 背景

Biome の推奨ルールには含まれない安定版ルールにも、変数参照の不具合防止や処理の意図の明確化に役立つものがある。
存在確認と値の取得を区別し、ループ内の関数が変化する外部変数を参照する危険を静的に検査したい。

## 決定

ループ内の関数による危険な変数参照と、存在確認に対して冗長な配列・正規表現の操作を、Biome の安定版ルールで検査する。
新規 nursery ルールは個別評価を行い、採用を決めたものだけを有効にする。

## 検討した選択肢

| 選択肢                                     | 評価                                                                   |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| **目的に合う安定版ルールを個別に追加する** | 意図が明確な検査を追加し、変更による不具合を防げる                     |
| 推奨ルールだけに依存する                   | 推奨対象外の変数参照や存在確認の検査をレビューに任せることになる       |
| nursery を含むルールを一括有効化する       | 使用していないフレームワークや既存契約と競合する検査も取り込んでしまう |

## 結果

- **良い点**
  - 存在確認を値の取得と区別でき、危険な変数参照を変更時に検出できる。
- **注意点**
  - 存在確認への書き換えはコールバックの実行回数などを変える場合があるため、自動修正の適用には振る舞いの確認が必要となる。
