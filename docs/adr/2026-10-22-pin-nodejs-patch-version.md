# Node.js のパッチバージョンを固定する

- **ステータス**: 承認
- **決定日**: 2026-10-22

## 背景

メジャーバージョンだけの指定では、既にインストール済みの古い Node.js が使われ続けることがある。
[セキュリティ更新](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)
を受け、開発・CI・ビルドで修正済みのバージョンを確実に使う必要がある。

## 決定

`.node-version` はパッチバージョンまで固定し、セキュリティ更新時に明示的に更新する。
`package.json` の `engines` の下限も同じバージョンに合わせる。
[Node.js のメジャーバージョンの選択](2026-09-24-nodejs-26.md)は維持する。

## 検討した選択肢

| 選択肢                           | 評価                                                           |
| -------------------------------- | -------------------------------------------------------------- |
| **パッチバージョンまで固定する** | 検証した修正済みバージョンを各環境で共有できる                 |
| メジャーバージョンのみ指定する   | 更新作業は少ないが、古いインストールが利用され続ける場合がある |

## 結果

- **良い点**
  - 開発・CI・ビルドで同じ修正済みバージョンを指定できる。
- **注意点**
  - セキュリティ更新のたびに指定バージョンの更新と検証が必要になる。
