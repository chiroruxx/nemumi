# OGP 画像に固定画像を使う

- **ステータス**: 承認
- **決定日**: 2026-10-10

## 背景

SNS でサイトを共有したときに、サイトの雰囲気と内容が伝わる OGP 画像を表示したい。ページごとに OGP
画像を自動生成する方法もあるが、現在はトップページと 404 ページのみで、ページごとの画像を作る要件はない。

## 決定

- SNS 用画像は固定の PNG とする。
- Open Graph 用には `public/ogp-square.png` を使い、サイズは 1200 × 1200 ピクセルとする。
- Twitter Card 用には `public/ogp.png` を使い、サイズは 1200 × 630 ピクセルとする。
- Astro の共通レイアウトで Open Graph と Twitter Card のメタ情報を設定する。

## 検討した選択肢

| 選択肢               | 評価                                                   |
| -------------------- | ------------------------------------------------------ |
| **固定画像**         | 管理が簡単で、SNS クローラーが取得しやすい形式にできる |
| ページごとに自動生成 | ページ固有の情報を表示できるが、生成処理と保守が増える |

## 結果

- **良い点**
  - SNS クローラーが取得できる絶対 URL の PNG を安定して提供できる。
  - Open Graph と Twitter Card で表示領域に合った画像を使える。
  - 追加の生成処理や依存パッケージが不要。
- **注意点**
  - ページ間で OGP 画像を使い分けない。
