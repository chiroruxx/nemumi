# コンテンツ自動更新

**ステータス: 未着手**

## 概要
各種サービスでコンテンツが更新された際に、自動でこのサイトのコンテンツも更新する。
更新はリアルタイムである必要はない。
RSSを用いて更新の確認を行う。

各種コンテンツとサービスの対応は以下である。
サービスなしのものは手動で更新するとして、このプロジェクトでは対象としない。

| サイトコンテンツ | 種別       | サービス               | サービスサイト                    |
|------------------|------------|------------------------|-----------------------------------|
| activities       |            | なし                   |                                   |
| articles         | 日常記事   | しずかなインターネット | https://sizu.me/chihiroxx         |
| articles         | テック記事 | はてなブログ           | https://toyo.hatenablog.jp        |
| communities      |            | なし                   |                                   |
| talks            | 登壇資料   | SpeakerDeck            | https://speakerdeck.com/chiroruxx |
