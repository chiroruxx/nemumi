# アクセス解析に Cloudflare Web Analytics を使う

- **ステータス**: 承認
- **決定日**: 2026-10-10

## 背景

サイトの利用状況や実際の閲覧環境におけるパフォーマンスを把握するには、継続的にアクセス解析を確認できる仕組みが必要である。Cloudflare
のダッシュボードでは、アクセス数、ページ表示数、ページロード時間、Core Web Vitals が確認できている。

## 決定

- サイト全体のアクセス解析と実利用環境のパフォーマンス確認に Cloudflare Web Analytics を使う。
- Cloudflare Web Analytics のダッシュボードを、アクセス数、ページ表示数、ページロード時間、Core Web Vitals の確認に使う。

## 検討した選択肢

| 選択肢                             | 評価                                                             |
|------------------------------------|------------------------------------------------------------------|
| **Cloudflare Web Analytics**       | 利用中の Cloudflare でアクセス状況と実利用環境の指標を確認できる |
| 別のアクセス解析サービスを導入する | 新たなサービスと設定の管理が必要になる                           |
| アクセス解析を導入しない           | 実際の利用状況や利用者環境での指標を継続して確認できない         |

## 結果

- **良い点**
    - 実際の閲覧から得た利用状況とパフォーマンス指標を確認できる。
    - Cloudflare の既存ダッシュボードで確認でき、別の解析サービスを追加せずに済む。
- **注意点**
    - ダッシュボードの指標は実際の利用状況に基づくため、アクセスが少ない期間は傾向を判断しにくい。
