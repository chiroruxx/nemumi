# 0008. 独自ドメインに nemumi.dev を採用する

- **ステータス**: 承認
- **日付**: 2026-09-24

## 背景

OGP・canonical・サイトマップは絶対 URL を使うため、公開の早い段階でドメインを確定させる必要がある。
後からドメインを変えると、シェア済みの URL や検索エンジンの評価が引き継がれない。

`nemumi.<TLD>` の形にすることは決めていた。2026 年 9 月時点で `nemumi.com` と `nemumi.net` は取得済みだった。
また、`.jp` は Cloudflare Registrar では取得できない。

## 決定

独自ドメインには `nemumi.dev` を採用し、Cloudflare Registrar で取得する。

- サイトの正式な URL は `https://nemumi.dev` とし、`astro.config.mjs` の `site` に設定する。
- Worker への紐付けは `wrangler.jsonc` の `routes`（`custom_domain: true`）に記載し、デプロイ時に反映する。
- `www.nemumi.dev` は使わない。

## 検討した選択肢

| 選択肢         | 評価                                                                                                          |
|----------------|---------------------------------------------------------------------------------------------------------------|
| **nemumi.dev** | 開発者向けの TLD で、エンジニアの個人サイトであることが伝わる。Cloudflare Registrar で取得でき DNS 設定が不要 |
| nemumi.jp      | 日本での活動が伝わるが、国内のレジストラで取得する必要があり、ネームサーバの設定が増える                      |
| nemumi.me      | 個人サイトの意味で使われるが、技術系の印象は `.dev` より弱い                                                  |
| nemumi.io      | 技術系でよく使われるが割高で、国別ドメインとしての管理体制が将来どうなるか不透明                              |

### 登録先

| 選択肢                   | 評価                                                                                        |
|--------------------------|---------------------------------------------------------------------------------------------|
| **Cloudflare Registrar** | 原価で更新でき、ホスティングと同じアカウントで DNS まで完結する。WHOIS の非公開が無料で既定 |
| 他のレジストラ           | 初年度が安いことがあるが、更新料金が高くなりやすく、ネームサーバの設定が必要                |

## 結果

- **良い点**
    - ドメイン・DNS・ホスティングを Cloudflare でまとめて管理できる。
    - Worker への紐付けがリポジトリに残る。
- **注意点**
    - `.dev` は HSTS preload の対象のため、HTTPS でしかアクセスできない。
    - 登録者情報は非公開だが、ICANN のルールにより正確な情報を登録しておく必要がある。
    - `wrangler deploy` で独自ドメインを反映するには、Workers Builds の API トークンに対象ゾーンの権限が必要。
