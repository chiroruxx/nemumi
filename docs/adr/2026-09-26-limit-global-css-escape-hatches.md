# Astro CSS で `:global()` の使用を制限する

- **ステータス**: 承認
- **日付**: 2026-09-26

## 背景

Astro の `<style>` は既定でコンポーネント単位にスコープされる。`:global()` を使うと、その境界を越えてスタイルが適用されるため、意図しない影響が起きる可能性がある。

一方で、ドキュメント全体に適用するスタイルや、スコープ外で生成される要素を対象にする場合には、グローバルなスタイル指定が必要になる。

## 決定

- サイト全体に適用するスタイルは、`src/styles/global.css`に記述する。
- Stylelint の `selector-pseudo-class-disallowed-list` で `:global()` を既定で禁止する。
- 必要な箇所では、対象ルールの直前に理由を記載した `stylelint-disable-next-line` コメントを付けて許可する。理由のない無効化コメントは
  Stylelint で検出する。

## 検討した選択肢

| 選択肢                               | 評価                                                         |
|--------------------------------------|--------------------------------------------------------------|
| 制限せずに使う                       | 柔軟だが、スコープを越える指定に気づきにくい                 |
| `:global()` を一切禁止する           | 境界は明確だが、サイト共通スタイルなどの必要な用途も制限する |
| **既定で禁止し、理由付きで許可する** | 通常のスコープを守りつつ、必要な用途を明示できる             |

## 結果

- **良い点**
    - 意図しないグローバルスタイルをLintで検出できる。
    - 例外に理由を残せる。
- **注意点**
    - 例外を追加するときは、対象ルールに理由付きの Stylelint コメントを付ける。
