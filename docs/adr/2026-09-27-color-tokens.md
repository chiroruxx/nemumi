# 色のトークンを用途と強調度で整理する

- **ステータス**: 承認
- **決定日**: 2026-09-27

## 背景

`on-xxx` の強弱を別々の色で定義しており、色相と強調度が同時に変化していた。通常の強調度には `-medium` が付いていた。

背景の星の色は `--decoration-star-*` という名前で、見出し横の星の色と区別しにくかった。
また、`--decoration-focus-wash` は名前に反してホバー時だけに使われ、固定色の `--color-surface-hover` は Surface
の変更に追従しなかった。
タグにも専用の背景色があったが、共通の Surface と区別する必要がない。
タグは補助情報として強調を抑え、文字色を背景の Surface に対応するロールに揃える。

これらを共通の命名と色の導出方針で整理し、管理する色を減らす。

## 決定

### on カラーの強調度

- 通常の強調度は `--color-on-xxx` とし、`-medium` を付けない。
- 強い強調度は `-strong`、弱い強調度は `-weak` を付ける。
- 各ロールの強弱は同じ RGB 値を使い、不透明度を strong は 100%、通常は 86%、weak は 66% とする。
- `on-background` と `on-surface` の RGB 値は `241 239 255`、`on-primary` と `on-secondary` は `28 27 50` とする。
- 不透明度は `rgb()` のアルファ値で指定する。

### 背景の星の装飾色

ページ背景の星の装飾色は `--decoration-background-star-*` と命名する。色を表す接尾辞と色の値は維持する。

### Surface と操作状態

- タグの背景色には `--color-surface` を使い、`--color-surface-tag` を削除する。
- タグの文字色には `--color-on-surface-weak` を使う。
- 操作状態の背景色は `--color-surface` に `--color-on-surface-strong` を重ねた色とする。
- `--color-surface-hover` は 8%、`--color-surface-focus` は 12% のオーバーレイに相当する色とする。
- sRGB でのアルファ合成に相当する色を `color-mix(in srgb, ...)` で生成する。
- `--decoration-focus-wash` を廃止し、アイコンリンク、404 ページのホームリンク、リンクカード、一覧のリンク行で共通の状態色を使う。
- フォーカス背景は `:focus-visible` に適用し、既存のフォーカス枠を維持する。

## 検討した選択肢

| 対象       | 選択肢                                   | 評価                                                 |
| ---------- | ---------------------------------------- | ---------------------------------------------------- |
| on カラー  | 強調度ごとに別の不透明色を使う           | 背景によらず色は固定されるが、強弱で色相も変わる     |
| on カラー  | **同じ色の不透明度を変える**             | 色相を統一し、既存の明暗差に近い強調度を表現できる   |
| 星の装飾色 | `--decoration-star-*` を維持する         | 短いが、どの星に使う色か判断しにくい                 |
| 星の装飾色 | **名前に background を含める**           | 背景用であることが参照箇所でもわかる                 |
| 操作状態   | 固定色や半透明の白を使う                 | 基準となる Surface との関係が不明確になる            |
| 操作状態   | 疑似要素でオーバーレイを重ねる           | 背景を保持できるが、重なり順や形状の管理が必要になる |
| 操作状態   | **Surface と on-surface の合成色を使う** | テーマ色に追従でき、通常の背景色として適用できる     |
| タグ       | タグ専用の背景色を維持する               | 個別に調整できるが、管理する色が増える               |
| タグ       | **共通の Surface を使う**                | 色の定義を減らし、Surface と統一できる               |

操作状態のオーバーレイは、フォーカスをホバーより強く表示するため、ホバーを 8%、フォーカスを 12% とする。

## 結果

- **良い点**
  - 色の用途と強調度を名前から判断でき、通常の on カラーを短い名前で参照できる。
  - タグと操作状態の背景色が Surface の変更に追従する。
  - 色に関する方針をひとつの ADR で確認できる。
- **注意点**
  - on カラーは背景と合成されるため、従来の不透明色とは見た目が変わる。
  - 操作状態の合成色は不透明であり、親の背景や装飾を透かす表現とは見た目が異なる。
  - タグの背景色は従来の `#36334f` から Surface の `#302b43` に変わる。
  - テーマ色を変更するときは、文字の読みやすさと操作状態の視認性も確認する。
