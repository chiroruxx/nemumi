# 0032. サイトのタイムゾーンを一元管理する

- **ステータス**: 承認
- **日付**: 2026-10-14

## 背景

サイトの日付は、RSS からの取り込みとページ表示で別々にタイムゾーンを指定している。取り込みは `Asia/Tokyo` に変換する一方、一覧の表示は
UTC で日付を取り出しており、サイトとして日付を扱う基準がコード上で統一されていない。

## 決定

- サイトのタイムゾーンを `src/config/site-time.ts` の `siteTimeZone` に定義する。
- 日時からサイト上の日付を作る処理は、同ファイルの `formatDateInSiteTimeZone` を使う。RSS の公開日変換とページの日付表示はこの関数を参照する。
- プロセスの既定タイムゾーンや起動時の `TZ` 設定には依存しない。

## 結果

- RSS 取得、コンテンツ表示で同じタイムゾーンを使い、実行環境のローカルタイムゾーンによる差を避ける。
- サイトのタイムゾーンを変更するときは、共通設定を変更すればよい。
