# 0016. 外部リンクを別タブで開く

- **ステータス**: 承認
- **日付**: 2026-09-27

## 背景

記事・活動やプロフィールなどの外部サイトを閲覧した後も、元のページを参照できるようにしたい。

## 決定

- 外部リンクを表示する `RecordListItem`、`LinkCard`、`IconLink` に `target="_blank"` を指定する。
- `rel="noopener noreferrer"` を併記し、遷移先からの元ウィンドウへのアクセスとリファラーの送信を防ぐ。
- サイト内のリンクとページ内リンクは同じタブで開く。
- 開き方は表示コンポーネントで管理し、コンテンツの YAML には追加しない。

## 検討した選択肢

| 選択肢                       | 評価                                               |
|------------------------------|----------------------------------------------------|
| **外部リンクを別タブで開く** | 元のページを保持したまま外部サイトを閲覧できる     |
| 同じタブで開く               | タブは増えないが、元のページに戻る操作が必要になる |

## 結果

- **良い点**
    - 外部サイトを閲覧しながら元のページを参照できる。
    - コンテンツごとに開き方を設定する必要がない。
- **注意点**
    - 外部リンクを開くたびにタブが増える。
    - 対象コンポーネントは外部リンク用とし、内部リンクを扱う場合は開き方を見直す。
