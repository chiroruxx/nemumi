# Zod でコンテンツの日付を解析する

- **ステータス**: 承認
- **日付**: 2026-10-14

## 背景

Astro のコンテンツスキーマは日付を `Date` に変換していたが、外部コンテンツの同期スクリプトは YAML
の日付を文字列として扱い、別の手書き検証を持っていた。RSS の日時もサイト上の日付に変換した後は文字列になり、Astro
とスクリプトで型と検証が分かれていた。

## 決定

- Zod を直接依存にし、Astro とスクリプトで `src/config/content-schema.ts` の共通日付スキーマを使う。
- YAML と RSS から読み込んだ日付は `Date` として処理し、日付の比較と並べ替えには `Date` の時刻値を使う。
- RSS の日時は読み込み時にサイトタイムゾーンの日付へ変換する。
- YAML への保存と CLI の表示では `formatDateInSiteTimeZone` を使い、`YYYY-MM-DD` 文字列にする。

## 結果

- Astro と同期スクリプトが同じ Zod スキーマで日付を検証・変換する。
- 日付処理中の型が `Date` に揃い、保存形式は既存の `YYYY-MM-DD` のまま保たれる。
- 日付の文字列化はサイトタイムゾーンを明示して行う。
