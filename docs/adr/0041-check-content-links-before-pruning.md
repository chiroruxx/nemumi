# 0041. 件数整理の前に保存済みリンクを確認する

- **ステータス**: 承認
- **日付**: 2026-10-17

## 背景

リンク切れの項目を含んだまま件数上限を適用すると、古い有効項目が上限超過分として削除され、その後で新しいリンク切れ項目も削除される。結果として保存数が上限未満になり、有効な古い項目も失われる。

## 決定

- Prune content workflow は、全コレクションのリンク確認と無効リンクの削除を先に行い、その後で件数上限を適用する。
- 未確認 URL は無効リンクとして削除せず、残った項目として件数上限の対象に含めて報告する。リンク確認自体が失敗した場合は件数整理と PR 作成を行わない。
- この決定は [ADR 0040](0040-separate-content-actions-by-responsibility.md) の Prune content の実行順序を置き換える。

## 結果

- 21件の同期管理記事で最新記事のリンクが無効と確認された場合、最新記事を削除してから上限を適用し、残る20件の有効記事を保持できる。
- Prune content workflow のリンク確認が件数整理より先に実行される。
