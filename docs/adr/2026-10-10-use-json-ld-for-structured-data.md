# 構造化データに JSON-LD を使う

- **ステータス**: 承認
- **決定日**: 2026-10-10

## 背景

検索エンジンなどがサイトの情報を理解しやすくするため、構造化データを提供する。構造化データには複数の記述形式があり、サイト全体で一貫した形式を選ぶ必要がある。

## 決定

- サイトの構造化データには JSON-LD を使う。
- 語彙には Schema.org を使い、各ページの内容に合う型とプロパティを記述する。
- 構造化データは、ページ上で利用者に示している情報と一致させる。

## 検討した選択肢

| 選択肢      | 評価                                                                      |
|-------------|---------------------------------------------------------------------------|
| **JSON-LD** | 表示用 HTML と分離して記述でき、ページの構造を変えずに追加・保守できる    |
| Microdata   | HTML 要素に構造化データを埋め込むため、表示マークアップとデータが結びつく |
| RDFa        | HTML 属性で意味を記述できるが、表示マークアップに記述が分散する           |

## 結果

- **良い点**
    - 表示用マークアップと構造化データを分けて管理できる。
    - サイト内で記述形式を統一できる。
- **注意点**
    - 表示内容を変更したときは、対応する構造化データも更新する。
