# 0003. Node.js 26 を採用する

- **ステータス**: 承認
- **日付**: 2026-09-24

## 背景

プロジェクトで使う Node.js のメジャーバージョンを決める必要がある。
2026 年 9 月時点の状況は以下のとおり。

- Node.js 24 は Active LTS で、2028 年 4 月までサポートされる。
- Node.js 26 は Current で、2026 年 10 月に LTS へ移行する予定。

## 決定

Node.js 26 を採用する。
`.node-version` ではメジャーバージョン（`26`）で固定し（[ADR 0002](0002-tool-version-management-mise.md)）、`package.json` の
`engines` は `>=26` とする。

## 検討した選択肢

| 選択肢         | 評価                                                            |
|----------------|-----------------------------------------------------------------|
| Node.js 24     | 現在の LTS で安定しているが、サポート期間は Node.js 26 より短い |
| **Node.js 26** | まもなく LTS に移行し、より長い期間使い続けられる               |

## 結果

- **良い点**
    - LTS 移行後、長期間にわたってメジャーバージョンを上げずに運用できる。
- **注意点**
    - LTS へ移行するまでの間は Current 版であるため、依存パッケージが未対応の場合がある。問題が出た場合は Node.js 24
      に戻すことを検討する。
