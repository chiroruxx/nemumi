# 0036. 公開状態を確認できない URL だけを報告する

- **ステータス**: 承認
- **日付**: 2026-10-15

## 背景

同期・削除の処理結果には、ファイル差分、保持項目、件数などが含まれる。これらは同じ実行の PR diff で確認でき、PR 本文や CLI
出力に重ねて表示する必要がない。公開状態を確認できない URL は diff から判断できないため、実行結果として報告する。

## 決定

- 同期・削除コマンドの stdout と GitHub Actions の summary には、`defer`、`review`、`unchecked` の URL だけを表示する。重複
  URL は1件にまとめる。
- 対象 URL がなければ、該当なしのメッセージを表示する。
- JSON 結果と変更、削除、保持、手動管理、件数の整形出力を廃止する。
- 同期で `defer` または `review` があれば失敗し、URL を報告してから終了する。未確認があれば同期を適用しない。削除では確認済みの無効
  URL と上限超過分だけを削除し、未確認 URL は保持する。
- [ADR 0025](0025-sync-external-content-from-rss.md) の dry-run と PR
  本文に変更内容を表示する決定、および [ADR 0029](0029-bound-content-network-execution.md)
  の詳細な処理結果を返す決定のうち、出力・報告に関する部分を置き換える。

## 結果

- PR diff が変更と削除の内容を示し、本文は人による確認が必要な URL に絞られる。
- 未確認 URL を含む同期は部分適用せず、削除では期限内に確定した削除だけを適用できる。
