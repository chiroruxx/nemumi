# UI パーツ単位で Astro コンポーネントに分ける

- **ステータス**: 承認
- **決定日**: 2026-09-26

## 背景

トップページのマークアップとスタイルが大きくなってきたため、管理しやすいコンポーネントの分け方を決める必要がある。

## 決定

ページのセクションではなく、役割や見た目のまとまりを単位に Astro コンポーネントへ分ける。

- ヒーローやコミュニティカードなど、独立して管理したい UI パーツをコンポーネントにする。
- 同じ形式の一覧は `RecordList` のような共通コンポーネントにする。
- 一覧の各行など、分ける必要が明確でない小さな要素は、必要になるまで親コンポーネント内に置く。
- Atomic Design の階層や分類は導入しない。

## 検討した選択肢

| 選択肢                             | 評価                                                           |
|------------------------------------|----------------------------------------------------------------|
| **役割や見た目のまとまりで分ける** | 関心ごととスタイルをまとめつつ、細かく分けすぎずに済む         |
| セクションごとに分ける             | 大きなページ構成は見やすいが、各セクションの部品はまとまらない |
| Atomic Design に沿って分類する     | 一貫した分類ができるが、現状の規模では階層管理が増える         |

## 結果

- **良い点**
    - UI パーツのマークアップとスコープ付きスタイルを近くで管理できる。
    - 独立させる必要が薄い小さな要素を無理にファイルへ分けずに済む。
- **注意点**
    - 切り出す単位は、再利用性や変更のまとまりを見ながら判断する。
