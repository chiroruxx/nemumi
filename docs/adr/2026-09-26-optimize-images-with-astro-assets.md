# astro:assets で画像を最適化する

- **ステータス**: 承認
- **決定日**: 2026-09-26

## 背景

プロフィールとコミュニティの画像を配信時に最適化し、表示サイズに合ったファイルを生成する方法を決める。

画像を `public/` に置くと Astro の画像処理対象にならないため、ビルド時に変換する画像は `src/assets/` で管理する必要がある。

## 決定

- 画像は `src/assets/` に置き、`astro:assets` の `Image` コンポーネントで表示する。
- 生成形式は WebP とし、画質は 85 にする。
- コミュニティアイコンの生成幅は最大 320px とする。
- プロフィール画像は 320px 四方で生成し、ファーストビューのため eager loading と高い fetch priority を指定する。
- Sharp を直接依存として追加し、ビルド時の画像変換に使う。

## 検討した選択肢

| 選択肢                             | 評価                                                         |
|------------------------------------|--------------------------------------------------------------|
| **astro:assets と Image を使う**   | 画像をビルド時に変換し、表示サイズに合わせた出力を指定できる |
| `public/` の画像をそのまま配信する | 管理が簡単だが、Astro の最適化処理を利用できない             |

## 結果

- **良い点**
    - 800px 四方のコミュニティ画像を 320px 四方に縮小して配信できる。
    - 現状の画像は、変換後にそれぞれ約 1.6〜9.1KB となった。
- **注意点**
    - ビルド環境に Sharp が必要となる。
    - 画質を変更する場合は、画像の見た目とファイルサイズを確認する。
