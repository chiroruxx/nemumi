# サイトマップと robots.txt を生成する

- **ステータス**: 承認
- **決定日**: 2026-10-10

## 背景

検索エンジンが公開ページを発見しやすくするため、サイトマップを提供する。サイトマップの URL は `astro.config.mjs` の `site`
を基準に生成する。robots.txt にも同じサイトマップの URL を記載する必要があり、ドメインを別々に管理すると設定が食い違う可能性がある。404
ページは検索結果に表示するページではない。

## 決定

- `@astrojs/sitemap` でビルド時に XML サイトマップを生成する。
- 404 ページはサイトマップに含めない。
- `robots.txt` は Astro のエンドポイントとして生成し、`site` を使ってサイトマップの絶対 URL を記載する。
- `robots.txt` では `User-agent: *` にサイト全体のクロールを許可する。
- HTML の `<head>` と `robots.txt` の両方からサイトマップを案内する。

## 検討した選択肢

| 選択肢                                    | 評価                                                               |
| ----------------------------------------- | ------------------------------------------------------------------ |
| **Astro integration と動的な robots.txt** | ページ一覧の生成を委譲でき、サイト URL の二重管理を避けられる      |
| XML と robots.txt を手書きする            | 依存は増えないが、ページやドメインの変更を手動で反映する必要がある |
| 静的な robots.txt                         | 単純だが、Astro の `site` と sitemap URL を別々に管理する          |

## 結果

- **良い点**
  - 公開ページの一覧とサイトマップ URL をビルド時に生成できる。
  - ドメインは Astro の `site` 設定を参照する。
- **注意点**
  - 新しい非公開ページを追加するときは、サイトマップへの掲載要否を確認する。
