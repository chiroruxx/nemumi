# 0018. コンテンツのタグを任意項目にする

- **ステータス**: 承認
- **日付**: 2026-10-10

## 背景

タグが不要なコンテンツにも空配列を記述する必要があり、データに意味のない記述が増える。タグがない状態をフィールドの省略で表現できるようにする。

## 決定

- Articles、Talks / Slides、Activities の `types` は任意項目とする。
- `types` を指定する場合は1つ以上のタグを含める。
- `types` の各要素は空文字および空白だけの文字列を許可しない。
- `types` が省略された場合は、表示時に空配列として扱う。

## 結果

- タグのないコンテンツでは `types` を省略できる。
- 明示的な空配列や要素のない配列は無効となる。
