# 0010. Astro のスコープ付き CSS を使う

- **ステータス**: 承認
- **日付**: 2026-09-26

## 背景

サイトのスタイリング方法を決める必要がある。サイトは Astro で実装し、ページやコンポーネントごとに見た目を管理する。

## 決定

Astro コンポーネントの `<style>` に CSS を記述し、スコープ付きスタイルを使う。

## 検討した選択肢

| 選択肢                       | 評価                                                           |
|------------------------------|----------------------------------------------------------------|
| **Astro のスコープ付き CSS** | 追加の依存がなく、コンポーネントごとにスタイルを管理できる     |
| 共通の CSS ファイル          | 全体のスタイルをまとめて管理できるが、局所的な変更も集約される |
| Tailwind CSS                 | クラスでスタイルを指定できるが、新たな依存と記法を導入する     |

## 結果

- **良い点**
    - コンポーネントのスタイルが他の要素に影響しにくい。
    - スタイリング用の依存を追加せずに済む。
- **注意点**
    - ページ全体で共有する CSS は、共通のスタイルとして管理する。
