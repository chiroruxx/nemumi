# 開発ワークフローの詳細をリポジトリ内のスキルで管理する

- **ステータス**: 承認
- **日付**: 2026-10-20

## 背景

`AGENTS.md` は各作業で読み込まれるため、常時必要な指針は短く保ちたい。一方、要件の整理や変更後の見直しなど、繰り返し使う工程には詳細な判断基準が必要である。

## 決定

- 繰り返し使う詳細な開発手順は、リポジトリ内で共有する Codex スキルに記載する。
- `AGENTS.md` には適用タイミングと短い判断基準を置き、該当するスキルへ案内する。
- プロジェクト文書を振る舞いの要件の正とし、スキルは要件の分類と実装・レビューの進め方を定める。

## 結果

- 実装手順を必要な作業で読み込める。
- 詳細な工程を `AGENTS.md` に重複して常時読み込ませずに済む。
