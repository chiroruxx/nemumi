# 0013. Astro のスコープ付き CSS でネイティブ CSS Nesting を使う

- **ステータス**: 承認
- **日付**: 2026-09-26

## 背景

Astro コンポーネントのスタイルで、親子関係のあるセレクターが同列に並び、関連が読み取りにくくなっている。

## 決定

Astro ファイルの `<style>` ではネイティブ CSS Nesting を使い、親子・状態・ブレークポイントの関係があるルールを該当するセレクターの内側に記述する。

## 検討した選択肢

| 選択肢                     | 評価                                               |
|----------------------------|----------------------------------------------------|
| **ネイティブ CSS Nesting** | 依存を追加せず、関連するルールを近くにまとめられる |
| フラットな CSS             | 標準的な記法だが、関連するルールが離れて並ぶ       |
| CSS プリプロセッサ         | 拡張記法を使えるが、追加の依存とビルド設定が必要   |

## 結果

- **良い点**
    - 親子セレクター、状態、レスポンシブ指定の関係を追いやすい。
    - 既存の Astro スコープ付き CSS を使い続けられる。
- **注意点**
    - ネストの深さを抑え、セレクターの意味が変わらないようにする。
    - Biome を整形と Astro 内の CSS 以外の Lint に使う。Astro 内の CSS Lint は Biome で無効にし、Stylelint に任せる。
    - Stylelint は標準 CSS ルールと `stylelint-use-nesting` を使う。Biome の整形と衝突する空行ルールは無効にする。
    - `mise run lint` は Stylelint を自動修正なしで実行し、整形・自動修正は Biome に一本化する。
