# 0004. パッケージマネージャに pnpm を採用する

- **ステータス**: 承認
- **日付**: 2026-09-24

## 背景

依存パッケージの管理に使うパッケージマネージャを決める必要がある。
Node.js 25 以降は corepack が同梱されないため、npm
以外を使う場合は別途インストールする必要がある（[ADR 0002](0002-tool-version-management-mise.md)）。

## 決定

パッケージマネージャには pnpm を採用する。
バージョンは `mise.toml` でメジャーバージョン（`12`）を固定する。Cloudflare Workers Builds では環境変数 `PNPM_VERSION`
で同じバージョンを指定する。

## 検討した選択肢

| 選択肢   | 評価                                                                             |
|----------|----------------------------------------------------------------------------------|
| **pnpm** | インストールが速く、ディスク使用量が少ない。宣言していない依存を使えないため安全 |
| npm      | Node.js に同梱されており追加のインストールが不要。小さなサイトなら十分           |

## 結果

- **良い点**
    - `package.json` に宣言していないパッケージを誤って使うことを防げる。
- **注意点**
    - pnpm は依存パッケージのインストール時スクリプトを既定で実行しない。スクリプトの実行が必要なパッケージは、
      `pnpm approve-builds` で許可する（許可した内容は `pnpm-workspace.yaml` の `allowBuilds` に記録される）。
