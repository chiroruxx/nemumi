# 0017. コンテンツデータの内容を検証する

- **ステータス**: 承認
- **日付**: 2026-10-10

## 背景

Content Collections のスキーマは必須項目と基本的な型を検証するが、空白だけの文字列、活動期間の前後関係、コミュニティの表示順の重複、CSS
の背景色として使えない値までは検出しない。これらの不整合をビルド時に検出する。

## 決定

- タイトル、タグ、コミュニティ名、コミュニティ紹介文、任意の活動説明文は、空文字および空白だけの文字列を許可しない。
- 活動の終了日は開始日以降の日付とする。
- コミュニティの `order` はコレクション内で重複させない。
- `imageBackground` は CSS の 3・4・6・8 桁の16進数カラー表記のみ許可する。
- スキーマで検証できる項目は Content Collections のスキーマで検証し、複数項目間の制約はトップページの生成時に検証する。

## 結果

- 不正なコンテンツデータを `astro check` または本番ビルド時に検出できる。
- `imageBackground` に CSS の名前付き色や `rgb()` 形式を使う場合は、スキーマを変更する必要がある。
